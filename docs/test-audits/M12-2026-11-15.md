   `return`s.
   - The one `it.fails` hit, `live-suite-census.test.ts`, is a comment.
   - Every source read was opened; see Appendix A.
3. **Body similarity** (`difflib`, 0.6 to 0.8) between every developer test and every QA test of each wave, and of M11 W1 and
   W3a. Every pair at 0.75 or above was opened and read side by side (the list is in Appendix A).
4. **A kill matrix** of line-level mutants over the added lines of the M12 production modules, and **title-directed mutants
   by hand**: about **130 mutants** in all (Appendix B).
   - A survivor became a row only where a test's title names what the mutant breaks.
   - A row is proved by other tests going red in the same run; those tests are named as the witness that the mutant
     landed.
5. **Reachability probes**, one throwaway test each, counted how often each W6f property reaches its assertion.

## Recommendations

   accepted population as well, with a stated floor on the runs that reach the assertion, as `contact-links.test.ts`

   determinism (`grep -i determin apps/web/tests/staff` finds only this file). The stateful-regex break is caught today only
   incidentally, by the 18 and 15 tests that call the builders on accepted values, so a determinism test is worth keeping
   once it can fail.

   `qa-m12-w6c-model.adversarial.test.ts`, which went red under the same mutant.

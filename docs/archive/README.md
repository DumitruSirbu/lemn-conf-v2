**Do not read these files unless you are asked a historical question.** They are kept so the history is
traceable, not as guidance. Each is superseded by the document named beside it, and acting on one risks
reintroducing a design or rule the project has since replaced. Current state is `docs/STATUS.md`; durable
reasoning is `docs/decisions/`.

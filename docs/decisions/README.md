# Architecture Decision Records

This directory is the project's decision log. In this repository an ADR records **our decisions and
findings** — why the code is shaped the way it is, what was tried and rejected, and what a review
turned up that changed a plan. It is not where the product's behavioural rules live: those are
`docs/design/DEVELOPMENT-SPEC.md`, cited by section and row (e.g. "§5.2", "§11 row 19"), never
duplicated into a decision record. A dated ADR supersedes earlier prose anywhere else in the
repo — `docs/CONFIGURATION_MODEL.md`, `docs/ARCHITECTURE_PROPOSAL.md`, milestone plans — but it
does not replace the behavioural spec as the source of truth for what the product does.

Read `docs/STATUS.md` first for where the project currently stands. Come here for the "why" behind a
piece of code; come here before re-deciding anything, since a dated record must not be silently
overturned.

| [0031](0031-a-resize-moves-a-whole-column-into-adjacent-empty-space.md) | A resize moves a whole column, and is funded by adjacent empty space | Accepted (remainder-floor bullet → **ADR 0043**, 2026-09-01) | Decision | M5 wave 5C — `setWidth` and the column update | **Supersedes §5.4's donor rule.** Implementing §5.4 as written produced **two reachable resizes in the whole shipped kitchen** — both sides of one boundary — because it takes the entire delta from one neighbour whose residue must be a legal width, and ADRs 0029/0030's 200 mm-granular sets almost never allow that. Supersedes the *mechanism* of 0029 and 0030, not their rules. **Amended 2026-08-27**: a hinged cabinet's widths are **two ranges** — one door 200–400, two doors 600–800 — not five discrete values, because the discrete set removed the hinged base cabinet from the 700 mm opening under the fridge where the builder makes an honest two-door. The generalisation: **a list of sizes that is the customer's menu is not automatically the engine's bound** — chips are what may be picked, ranges what may be built, a floor what may not be crossed, and `CatalogOffer` now publishes all three separately. |

| [0035](0035-width-is-a-bounded-stepper-not-a-menu-of-sizes.md) | Width is a bounded ±50 mm stepper, not a menu of sizes | Accepted | Decision | M5 — supersedes wave 5D's chip row, gates 5E | Six ADRs in a row (0026, 0029, 0030, 0031, 0033, 0034) each answered *which numbers belong in this entry's size list*, and together described a model fighting itself: the engine had already been pushed to ranges while the catalogue hand-maintained a menu and the panel rendered it as chips.
